# 🏗️ Construction Project OS — منصة تشغيل مشاريع التشييد

نظام تشغيل متكامل لإدارة المشاريع الإنشائية الضخمة (Project OS) — وليس أداة مهام.
A full Construction Project Operating System for mega projects — not a task tool.

**عربي أولاً مع دعم RTL كامل · Arabic-first with full RTL · English supported**

## التشغيل · Run

لا يحتاج أي تثبيت أو خادم — افتح `index.html` مباشرة في المتصفح.
No build, no server — just open `index.html` in a browser.

```bash
# أو شغّل خادماً محلياً اختيارياً
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

البيانات تُحفظ محلياً في المتصفح (localStorage) مع بيانات تجريبية واقعية لمحفظة من 8 مشاريع ضخمة، 6 مقاولين، و400+ سجل.

| المركز | Center |
|---|---|
| 🗂️ مركز اختيار المشاريع (تجميع حسب البرنامج/المنطقة/العميل/الحزمة/المقاول) | Project Selection Center |
| 🎯 مركز القيادة التنفيذية — غرفة عمليات | Executive Command Center (war room) |
| ⚡ مركز إدارة الإجراءات — مرتبطة بمصادرها، تقادم، متأخرات، مصفوفة مسؤولية | Action Management Center |
| 🛡️ مركز ذكاء المخاطر — خريطة حرارة، اتجاهات، تقادم، تنبؤ، تصعيد، خطط معالجة بالذكاء الاصطناعي | Risk Intelligence Center |
| 🧩 مركز المعضلات — سبب جذري، إجراءات تصحيحية/وقائية، تحليلات إغلاق | Issues Management Center |
| 📸 مركز الملاحظات الميدانية — معرض/كانبان/خط زمني/خريطة/قائمة + مسارات اعتماد | Site Observation Center |
| 🏗️ مركز أداء المقاولين — ملفات، عقود، 5 أبعاد تقييم، ترتيب، اتجاهات | Contractor Performance Center |
| ✉️ مركز المراسلات — وارد/صادر، مهل الرد، متابعة تلقائية، تصعيد | Correspondence Center |
| 🗓️ مركز الاجتماعات — تقويم، محاضر، قرارات، تتبع إجراءات | Meeting Management Center |
| 💡 مركز الدروس المستفادة — قاعدة معرفة بمحرك بحث عبر المحفظة | Lessons Learned Center |
| 📐 مركز ضبط الوثائق — مخططات، ITP، بيانات طريقة عمل، RFI، إصدارات واعتمادات | Document Control Center |
| 📊 منشئ لوحات المعلومات — سحب وإفلات، KPIs مخصصة | Dashboard Builder (drag & drop) |
| 🔀 منشئ مسارات العمل — موافقات/مراجعات/إشعارات/تصعيد دون برمجة | Workflow Builder (no-code) |
| ✨ المساعد الذكي — تقارير وملخصات من بياناتك الفعلية | AI Assistant (works on live data) |
| 🛠️ مركز التحكم الإداري — وحدات، حقول، حالات، فئات، وسوم، مستخدمون، صلاحيات | Admin Control Center |

## قابلية التهيئة · Configurability

كل شيء قابل للتعديل دون برمجة من مركز التحكم الإداري:
إظهار/إخفاء الوحدات وإنشاء وحدات مخصصة، إضافة حقول مخصصة لأي سجل،
تعديل الحالات وألوانها، الفئات والوسوم، إدارة المستخدمين ومصفوفة الصلاحيات.

البنية قائمة على المخططات الوصفية (metadata-driven): محرك سجلات واحد
يولّد النماذج والعروض (قائمة/كانبان/معرض/خط زمني/خريطة) من تعريف كل كيان.

## التقنية · Tech
